# 🔴 Color Ball Game

An interactive web game built entirely within a single HTML file. This game is designed to be extremely lightweight, fast-loading, and playable directly in your browser without requiring any app installations.

## 🎮 Play Now
[**Click here to play**]((https://matt-mal-00.github.io/Color_Ball_Game/)) 

## ✨ Key Features
* **Single-File Architecture:** The entire structure (HTML), visual styling (CSS), and game logic (JavaScript) are combined into one `index.html` file.
* **Offline-Ready:** Built without external server dependencies, meaning the game can be downloaded and played smoothly even without an internet connection.
* **Cross-Device:** Fully responsive and playable using a mouse on a PC or a touch screen on mobile devices.

## 🚀 How to Run Locally
If you want to play this game offline on your own device:
1. Download the `index.html` file from this repository.
2. Open the file using any web browser (Google Chrome, Mozilla Firefox, Safari, etc.).

## 🛠️ Technologies Used
* HTML5
* CSS3
* Vanilla JavaScript (DOM / Canvas API)
